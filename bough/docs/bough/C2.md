# C2: reach() vs the three OSAHR schedulers

Claim C2 is that Bough's embedded jump-chain `reach()` agrees with first-passage
frequencies from OSAHR's three exact schedulers:

- `direct_ssa`
- `next_reaction`
- `thinning`

on a **DAG**. The ontology fragment is cyclic (relapse) and is out of scope;
`reach()` refuses `CYCLIC_AUTOMATON` there. Thinning is included as a scheduler
identity. Bough still refuses time-varying hazards, so thinning runs the same
piecewise-constant law as the other two (the kernel uses the hazard itself as
the bound when `hazard_upper_bound` is absent).

This is not a speed claim.

## Families

**Race.** One vertex, two irreversible competing jumps, rates 2 and 1.
Exact `reach(a) = 2/3`, `reach(b) = 1/3`, one path each. One kernel event
selects the winner.

**Bits n=2.** Irreversible independent flips. Exact `reach(all-on) = 1` over
2 paths. Two kernel events absorb with probability 1. Absorption-only is a
weak check; the race is the non-trivial mass.

## Alarm, not a proof

Each scheduler runs `n` independent seeded replicates via `osahr.analysis.run_ensemble`
with the reference matcher. Agreement is

```text
|empirical − exact| ≤ sqrt( log(2/α) / (2n) )
```

with `α = 1e-6`. For `n = 96` that radius is about 0.275, which is inside `(0, 1/3)`,
so an always-`a` scheduler fails against `2/3`. The bound is a regression alarm.
It does not establish distributional equality, and it does not license quoting
C2 as a theorem about arbitrary OSAHR models.
